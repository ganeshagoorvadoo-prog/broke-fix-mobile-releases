# Broke Fix Mobile — downloads

Installers for **Broke Fix Mobile** by Kairo Labs LTD. No source code lives here.

## Android
1. On your phone, open the [latest release](https://github.com/ganeshagoorvadoo-prog/broke-fix-mobile-releases/releases/latest) and download the `.apk` file.
2. Open the downloaded file. If Android asks, allow your browser to "install unknown apps".
3. Tap **Install**.

The app checks this page for new versions and shows an **Update** button when one is out.

## Windows
Download the `.exe` from the latest release (when available). It updates itself.
